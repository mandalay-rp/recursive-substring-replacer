# replace.sh

Читать на [English](README.md)

Скрипт на Bash для **рекурсивной замены строки** внутри текстовых файлов каталога.

- Заменяет литеральную подстроку (все метасимволы экранируются автоматически)
- Пропускает бинарные и пустые файлы
- Не трогает файлы без совпадений (быстрая предпроверка через `grep -F`)
- Поддерживает dry-run, резервные копии, замену только первого вхождения и игнорирование регистра
- Работает с GNU sed (Linux) и BSD sed (macOS)
- По умолчанию исключает каталог `.git`

## Требования

- `bash` 4+
- `find`, `grep` (GNU или BSD)
- `sed` (GNU или BSD)
- Для флага `-i` (игнор регистра) требуется **GNU sed**

## Установка

```bash
git clone <repo-url> replace
cd replace
chmod +x replace.sh
```

Или просто скопируйте `replace.sh` в удобное место и сделайте исполняемым:

```bash
chmod +x replace.sh
```

## Использование

```bash
./replace.sh [-d DIR] [-n] [-b] [-f] [-i] "что" "на что"
```

| Опция | Описание |
|-------|----------|
| `-d DIR` | Каталог для обработки (по умолчанию — текущий) |
| `-n` | Dry-run: только показать файлы, которые были бы изменены |
| `-b` | Сохранять резервные копии рядом с файлом (суффикс `.bak`) |
| `-f` | Заменить только первое вхождение в каждом файле (по умолчанию — все) |
| `-i` | Игнорировать регистр при поиске (требует GNU sed) |
| `-h` | Показать справку |

## Примеры

Сухой прогон — посмотреть, что будет изменено:

```bash
./replace.sh -n -d ./src "foo" "bar"
```

Заменить с резервными копиями `.bak`:

```bash
./replace.sh -b -d ./src "foo" "bar"
```

Заменить только первое вхождение в каждом файле:

```bash
./replace.sh -f -d ./src "foo" "bar"
```

Без учёта регистра (GNU sed):

```bash
./replace.sh -i -d ./docs "hello" "world"
```

## Как это работает

1. Строка поиска трактуется как **литеральная**: символы `\ . * [ ] ^ $ /` и др. экранируются.
2. В строке замены экранируются `\`, `/` и `&`.
3. Каждый файл предварительно проверяется через `grep -F`:
   - бинарные и пустые файлы пропускаются;
   - файлы без совпадений не перезаписываются.
4. Замена выполняется через `sed -i` с автоопределением GNU/BSD синтаксиса.
5. По завершении выводится статистика: сколько файлов изменено и пропущено.

## Ограничения

- Ищется только **одна и та же литеральная подстрока** — регулярные выражения не поддерживаются.
- Замена в бинарных файлах не производится.
- Каталог `.git` исключён; другие исключения (например, `node_modules`) можно добавить в вызов `find` внутри скрипта.
- Флаг `-i` (игнор регистра) не работает на BSD sed (macOS).
